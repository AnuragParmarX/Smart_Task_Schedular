
# Smart Task Scheduler & Workflow Automation Engine

## Overview

Smart Task Scheduler & Workflow Automation Engine is a Java Spring Boot application that helps users manage tasks, schedule recurring jobs, define task dependencies, automate workflow execution, and receive reminders.

The project demonstrates enterprise Java concepts including layered architecture, Spring Boot, REST APIs, JPA/Hibernate, scheduling, multithreading, logging, and database management.
